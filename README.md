# Coastal Upwelling and El Niño Events Reduce Mesozooplankton Morphological Diversity in the Southern California Current Ecosystem
## Rubén Tournier-Broer, Mati Kahru, Sakina-Dorothée Ayata, Tristan Biard, Mark D. Ohman

This repository contains the code used in a study investigating variations in mesozooplankton morphological traits and diversity in the California Current Ecosystem across environmental gradients.

## Installation
First, download or clone this repository. The associated data must then be downloaded from Zenodo and placed in the /data directory.

Image files are not accessible. Consequently, the section of the code entitled “Plot morphological space” cannot be executed.
